# Mateus Miranda

**Senior Dynamics 365 CE / Dataverse Engineer building AI into business applications.**

I've spent 22 years in tech, 15 of them in the Microsoft ecosystem and more than 10 working exclusively with Dynamics 365. I started at 18 running my own LAN house and computer store, went on to build systems for health insurers, moved into consulting, and then spent years on large enterprise Dynamics projects. Today I focus on bringing AI into business apps: agents, RAG, MCP and Azure OpenAI wired into Dynamics and Dataverse in a way that is secure, testable and ready for production. I care about results, not demos — engineering that moves a business metric.

## What I work on

- **Dynamics 365 CE / Dataverse** — plugins, custom APIs, Web API integrations, data modeling and performance.
- **AI for business apps** — Azure OpenAI, AI agents, retrieval-augmented generation (RAG) and MCP servers that let agents work with CRM data safely.
- **Power Platform** — PCF controls (TypeScript/React), model-driven apps, solution ALM and CI/CD.
- **Azure** — Functions, Azure OpenAI and AI Search as the backbone for intelligent integrations.
- **Python for AI** — FastAPI services, LLM tooling, data analysis and machine learning.
